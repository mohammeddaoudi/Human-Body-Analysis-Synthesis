# Human Body Analysis and Synthesis

Course website for engineering students in AI and health.

Website: https://mohammeddaoudi.github.io/Human-Body-Analysis-Synthesis/

## Structure

- `docs/index.html`: landing page on GitHub Pages
- `docs/chapters/`: one page per chapter
- `docs/assets/style.css`: shared styles
- `docs/slides/`: lecture slides in PDF format
- `docs/demos/`: interactive HTML/JavaScript demonstrations
- `docs/exercises/`: PDF exercise sheets and practical work
- `notebooks/`: Python notebooks
- `src/`: reusable Python code

## Publishing

GitHub Pages is configured to publish the `/docs` directory on the `main` branch.

To update the site:
1. Add new PDF or HTML resources in the corresponding folder.
2. Edit the relevant `docs/chapters/<chapter>/index.html` page to replace the 'Coming soon' label with an appropriate link.
3. Commit changes to `main`. GitHub Pages will rebuild.

Only PDF lecture slides are published. Keep the PowerPoint originals on your own computer.
